# Faculty Directory Web App

A compact, browser-based faculty directory application built with plain HTML, CSS, and JavaScript.

This project provides a single-page interface for browsing, searching, and managing faculty profiles entirely in the browser. All data is stored in the browser's localStorage so changes persist across refreshes.

## Key Features

- Directory view with searchable faculty cards.
- Profile details displayed when a faculty card is selected.
- Add / edit faculty form with validation and pre-filled data for updates.
- Browser-based persistence using `localStorage`.
- Reports view summarizing the faculty list.
- Sample faculty data loads automatically when no saved records exist.

## Files

- `faculty final.html` — main application file containing the UI and JavaScript logic.
- `README.md` — this project documentation.

## How to Run

1. Open `faculty final.html` in any modern web browser.
2. The app loads sample data if no saved faculty records are found.
3. Use the Directory screen to browse, search, and select faculty profiles.
4. Click Add Faculty or edit an existing profile to save changes.

## Notes

- No backend server is required.
- Works offline after the file is opened in the browser.
- Data is saved locally in the browser and is not shared across devices.

## About

This simple web app is ideal for demonstrating client-side state management, form handling, and browser persistence with a clean, single-page user experience.
